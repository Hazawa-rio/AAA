# 網頁 RPG — 戰鬥測試（單機版）

純前端，不需要伺服器：**直接雙擊 `index.html` 就能玩**，也可以原封不動放上 GitHub Pages。

流程：`index.html` 選角色和房間 → `battle.html` 戰鬥。房間有「新手引導」（NPC 教學，固定角色）、「史萊姆測試房」（3 隻史萊姆）和「古代遺跡」（Boss）。場地 1280×720。

## 共用規則

- **行動順序**：第一回合開始時，所有單位擲 1d20 ＋ 速度，高的先動（同分比速度，再同分玩家先）。之後每回合都沿用這個順序。
- **行動點**：畫在角色頭上的藍色小菱形（要花掉的那幾點會變紅）。每到自己回合補滿。移動、普攻、技能都花行動點。
- **非自己回合**：敵人的回合中（包含撞擊倒數時）也可以做任何行動，但行動點消耗 ×2，大招除外。自己回合沒用完的點數就是留給這時候用的。被攻擊時不會跳出提示，要自己看紅框。
- **冷卻 / 充能**：只有**自己回合內**、有消耗行動點的行動才會讓冷卻減 1、大招充能 +1。非自己回合的應急行動、上膛後免費射箭都不算。
- **普攻按 A**：所有角色都可以按 A 進入普攻瞄準，不用指定敵人，點地面就朝那個方向出手（點敵人照舊直接打）
- **護盾**：先扣護盾再扣生命（上限＝最大生命的 80%），角色頭上的藍框、血條上方的藍線
- **虛弱**：造成的傷害降低（倍率看技能）；**去除負面狀態**的順序：麻痺 → 破防 → 虛弱 → 行動點減少
- **傷害公式**：`基礎 × (1 + 攻擊力/100) − 防禦`，最少 1。寫在 `js/config.js` 的 `damage()`，換公式只改那裡。

## 新手引導房

NPC「羽澤璃央」一步一步教戰鬥系統，劇本在 `js/tutorial.js`：

1. 開場對話 → 自由移動（不消耗行動值），走到她旁邊按 **E**
2. 她後退一步、在面前生出心魔 → 只開放普攻，擊殺心魔
3. 行動值與技能說明 → **在 6 點行動值內疊滿 5 層陰霾**（第一隻心魔要用 Q 拉過來才打得到，之後的都會出現在身邊）。行動值用完沒疊滿就整個重來
4. 應急行動說明 → 立刻戰鬥，她先手揮鐮刀（扇形預告、3 秒）。成功閃開一次後暫停對話，然後以 50 生命正式開打
5. 她只會移動和揮砍（7 行動值）。血條打光不會倒下，之後行動值無限，可以自由測試

教學期間打她不會有傷害，她會吐槽（普攻隨機三句、Q「你撞到我了」、E「你炸到我了」）。

這個房間固定使用 `js/characters/ilshu-tutorial.js` 的**教學版伊爾舒**：技能行為沿用伊爾舒，但數值全部寫死在這個檔案，之後調整 `ilshu.js` 的平衡數值不會影響教學；選角頁也不會顯示它。NPC 的數值同樣固定在 `tutorial.js`。

## 技能標籤

技能卡上的標籤（`tags`），寶物會看標籤決定效果：投射物（`projectile`）、範圍（`area`）、近戰（`melee`）、召喚物（`summon`）、**護盾**（`shield`）、**強化**（`buff`）

- 護盾：會給護盾的技能。觀知命的金剛咒符、趨吉避凶、乾坤挪移；蒼幽的海馬先生
- 強化：會讓技能升級成強化版的技能。薇薇拉的加大劑量（普攻變強）、霍夫曼的壓縮加速機（普攻變成亞光速撞擊）、瑪莉卡的燃起火焰（普攻變成火舌折磨）

## 個性台詞

角色使用技能時頭上會跳出台詞泡泡，不會每次都跳（每句有出現機率，同一個角色 2.5 秒內不重複，比較特別的台詞可以蓋掉普通的）。台詞與機率寫在角色檔的 `barks`。

## 敵人：史萊姆

低智力，輪到它時一定把 3 點行動點用完：

1. **壓制**：玩家在撞擊距離外、施放距離內 → 紅色虛線圓蓄力，下次輪到它時跳到圓心落下。
2. **撞擊**：玩家夠近 → 紅色長方形框，倒數 1 秒後打中框內的人。倒數中把它打倒，撞擊就會中斷。
3. **移動**：往玩家靠近，被其他史萊姆擋住會繞過去。

壓制落下後要再做 2 次行動才能再用。

## 時空酒館（地圖測試）

`tavern.html`（選角頁標題旁有連結）。正式版的流程：登入（Google 或遊客）→ 取名字 → 詢問要不要先進行戰鬥系統教學 → 以「只有名字的方塊」走進酒館。測試版只有遊客登入，資料存在瀏覽器；「切換帳號」可以重新登入。

- 酒館位在時空縫隙之間的異次元，窗外是不停變色的時空亂流
- 移動：點地板走過去；點物件會先走過去再互動（靠近時也可以按 E）
- **酒保 桑恩**（吧檯後面，另一頭留了以後放 NPC 的位置）：可以問他「這間酒館是什麼地方」「適格者是什麼」「你是誰」，或來杯特調。基底隨機，調料最多 5 份、照加入順序排列，每份 10 時空幣：

  | 調料 | 下一次進入委託時 |
  |---|---|
  | 櫻桃汁 | 生命 +5 |
  | 魔力冰塊 | 魔力 +5 |
  | 辣椒根 | 攻擊 +3 |
  | 無花果結晶 | 防禦 +2 |
  | 天界香草 | 速度 +1 |

  特調在進入下一場委託（戰鬥）時喝掉，同一頁「再來一場」仍然有效；教學不會用掉
- **時空委託欄**：「時空委託」分頁接下各個時空的委託單；「戰鬥測試」分頁直接開打（也可以重新進行新手教學）
- **出入口**：帶著委託走出去，就會抵達委託所在的時空；接下的委託全部完成才能回到酒館（在時空裡打開酒館頁會被擋下）
- **適格者名牌架**：選擇出發的適格者；架上只掛玩家精選的 3 位
- **收音機**（吧檯右邊）：平常放爵士樂（`sounds/tavern-jazz.mp3`，瀏覽器要等玩家先點一下畫面才會開始）；可以關掉，或貼 YouTube 連結換成想聽的音樂（右下角的小視窗播放，可以收起；設定存在 `rpg.radio`）
- **懸掛電話**：產生訊號（6 位數房號）、撥打號碼（多人遊戲尚未開放，只有介面）
- **天文望遠鏡**：觀測適格者（抽角色，之後開放）
- 桌椅：之後多人準備階段打牌用（還沒做）

**時空幣**（局外貨幣）：新帳號 100（測試用），委託勝利獲得：史萊姆 30、古代遺跡 80、受難之日 250。調酒介面有測試用的「+100 時空幣」。

從酒館出發的戰鬥（網址有 `from=tavern`），返回連結會回到酒館。

### 適格者名牌架、天文望遠鏡（觀測）

- **名牌架**：點名牌選角色，下面會顯示那位適格者的正式簡介；還沒取得的適格者是虛線的名牌（點了可以看簡介）
- **掛在架上的名牌**：架上不會掛出所有角色，玩家在面板裡點選要掛的適格者（最多 3 位、至少 1 位，存在 `rpg.rackShow`）；沒選過就掛前 3 位
- **天文望遠鏡＝觀測（抽角色）**：觀測 1 次 500 時空幣、10 次 5000 時空幣。每次觀測的結果：
  - 適格者：1.5%（平均分給還沒取得的適格者）；先「定向觀測」選一位，他的機率翻倍成 3%（其他人 0%）
  - 其他是時空碎片：傳奇 25～32 個、史詩 10～17 個、稀有 1～7 個（傳奇 4%、史詩 19.5%、稀有 75% 是暫定，扣掉適格者後依比例）
  - 1000 個時空碎片可以兌換一位還沒取得的適格者；已經取得的適格者不會再被觀測到
- 觀測動畫：圓形的鏡框在時空亂流中掃視，最後找到一顆星星——顏色是這次最好的結果：稀有藍、史詩紫、傳奇金；觀測到適格者是那位角色自己的顏色，加上額外的閃光（同時抽到兩位就隨機挑一位）。可以按「跳過」
- （測試）天文望遠鏡裡可以把抽到的角色還回去，方便重複測試觀測
- 資料存在瀏覽器：`rpg.owned`（已取得的適格者）、`rpg.shards`（時空碎片）；弗爾斯勒、伊爾舒、薇薇拉一開始就有

- **委託流程**（`stages`）：先到委託人面前的**圓形判定框**裡和他談（多人時所有玩家都要站進框裡才能進行劇情）→ 照委託做事 → 回去找委託人回報

- 地圖戰鬥打完會在 `run.lastBattle` 記下結果（`result`、`variant`），各時空的玩法用它判斷「剛剛嚇跑的是哪一隻」

### 委託執照與冒險

- 委託執照：**C → B → A → S → SS → SSS**，時空標示需要的等級（`rank`），執照不夠的時空不能接。目前只有 C 級時空
- **每輪冒險從 C 開始**：第一次從酒館出發時開始一輪冒險，之後連續前往各個時空、完成委託、升級執照、去更難的時空
- **執照經驗**：完成委託拿到執照經驗（C 級委託 120～280），升級門檻差距很大：B 1500、A 8000、S 30000、SS 100000、SSS 300000（`RANK_XP`）
- **金幣與行囊跟著冒險走**：完成委託回到酒館不會重置，下次出發繼續帶著；生命每次出發都是滿的
- **同一輪冒險完成過的委託不能再接**（不能重複刷）
- **全員戰敗＝委託失敗**：這輪冒險結束、回到酒館，執照回到 C。完成的委託照常拿報酬；沒完成的委託只能照進度比例拿時空幣（沒有經驗）
- **前期運營＝時空內的重新成長**：每輪冒險的等級、強化點、技能強化、寶物都從零開始（存在 `rpg.adv.build.<角色>`），冒險結束就清掉。選角頁和「戰鬥測試」用原本的測試存檔（`rpg.build.<角色>`），互不影響
- 時空幣之後主要用在天文望遠鏡「觀測適格者」（抽角色）
- 委託欄的「結束這輪冒險」可以自己結束（只在酒館準備時）
- 資料存在 `rpg.adventure`（`R.Adventure`，寫在 `js/commissions.js`）

## 地圖探索（`world.html`）

- 玩家是選好的適格者方塊（保留自己的名字，HUD 上點名字可以隨時改名）
- 左鍵點地板移動、點 NPC／物件互動；**右鍵切換「移動／攻擊」模式**
- **委託人的對話框**：和 NPC 說話（除了桑恩、商店這種有介面的）是像新手引導一樣的對話框，台詞在畫面下方；委託選項（聽聽委託內容、回報）和個性化選項（適格者專屬的對話）放在對話框**右側上方**。委託劇情一句一句播，點對話框就繼續
- 右上角的「**指示：收起／展開**」可以把委託指示收起來（記在瀏覽器裡）；對話框開著的時候指示也會先藏起來，免得點到
- **攻擊模式＝戰鬥中的普攻**：點哪裡就朝哪裡用角色的普攻（同樣的形狀、範圍、音效）：弗爾斯勒踢腿＝面前一小塊方形、伊爾舒長劍突刺＝細長的直線、薇薇拉投擲蘑菇＝丟到一個點炸開、觀知命金剛咒符＝飛出去的符、霍夫曼變形扳手＝扇形。打到魔物＝以迎戰（先手）開始戰鬥；點範圍外的魔物會先走過去再打。時空可以接住普攻（`HOOK.basicHit(test)`），例如月台上的逃票客打中就算抓到
- 地圖上行動值無限，只能移動、普攻、使用 Q 技能（即時冷卻）：

  | 適格者 | Q | 冷卻 | 效果 |
  |---|---|---|---|
  | 弗爾斯勒 | 射出箭矢 | 30 秒 | 點方向射出，命中遠處敵人觸發迎戰（之後也能觸發機關） |
  | 伊爾舒 | 疑心病 | 25 秒 | 蓄力感測周圍；有陷阱或敵人「我感到有些不適」，否則「看來是想多了」 |
  | 薇薇拉 | 拋出蘑菇 | 45 秒 | 少量治療（15%）；給自己「我開動了」，給隊友「這個給你...」（多人前只能給自己） |

- 敵人在原地附近遊盪；**被碰到＝遇襲（先手值 −2）**，**先攻擊敵人＝迎戰（先手值 +3）**，簡單轉場後進入戰鬥（`room=encounter`）
- 戰鬥結束回地圖：勝利保留剩餘生命、得到金幣與掉落物，那群敵人消失；戰敗＝冒險失敗（見上面）
- **掉落物**：史萊姆 → 黏液；魔狼 → 魔狼的牙、魔狼的肉（`enemies.*.drops`）。素材可以賣給商店；魔狼的肉帶回酒館可以請桑恩烤成「烤魔狼肉」（回復 45% 生命）
- **魔狼群**：在草原遊盪，玩家進入 280 px 內會主動撲過來（頭上跳出紅色驚嘆號），離家太遠才放棄；地圖上一群顯示 2～3 隻
- **鎮民**：幾位鎮民在鎮上遊盪（只是遊盪）
- **商店**：漁會、商人公會、海上市集。委託沒完成前只賣小瓶生命藥水（30 金幣，回復 30% 生命）和小瓶魔力藥水（30 金幣，戰鬥中回復 40% 魔力）；完成奇儂鎮的任一張委託後，各店開放專屬寶物（稀有度：普通，寶物會加在這輪冒險的寶物欄）。「賣」分頁可以賣素材
- **戰鬥中用道具**：地圖戰鬥的「道具」按鈕，用一次花 1 行動點（非自己回合 ×2）
- 所有魔物戰鬥使用一般戰鬥 BGM；地圖有奇儂鎮 BGM；遇敵時播放遇敵音效。右上角可以開關音效
- **草原的戰鬥**：草地背景，場上隨機 3～5 叢草叢（`terrain.grass`）。站在草叢裡的單位（敵我都一樣）受到攻擊時 40% 打空；任何攻擊的範圍碰到草叢（斬擊、箭、爆炸、撞擊、壓制…）都會把它一起破壞，那一擊仍然算隱蔽
- **撤退**：地圖小怪戰的「結束回合」旁有「撤退 xx%」按鈕，離最近的敵人越遠成功率越高（120 px 內 15%，650 px 外 90%，`rooms.encounter.retreat`）。成功＝回到地圖、魔物還在、3.5 秒內不會被撞到；失敗＝直接結束回合。地圖戰鬥不能直接離開頁面撤退
- **行囊 20 格**（任務道具、消耗品、素材，I 鍵；`js/bag.js`）；**金幣**這輪冒險都能用
- 看不見的陷阱（扣最大生命 10%）、可以撿的回復藥草與金幣
- 特調在出發時喝掉，效果持續整趟冒險

## 試煉 Boss：受難之日

生命 3200・攻擊 60・防禦 14・速度 14・行動點 7（全部暫定，數值面板可以調）。畫面正上方有帶名字的大血條，黃色刻度是變身門檻。

### 第一階段（不會移動）

開場帶著 4 隻**復甦的混亂教徒**和 1 隻**復甦的混亂教皇**。

| 招式 | ★ | 說明 |
|---|---|---|
| 揮砍 | 1 | 往上／下／左／右其中一個方向揮出大範圍斬擊（長 560、寬 300，有預告）。智力高，大多會選打得到玩家的方向 |
| 制裁 | 1 | 劍尖指向玩家，發射細長雷射（寬 34，有預告） |
| 無序者的救贖 | 2 | 把劍插進地面蓄力，下次輪到它時從自己往外擴散到全圖的同心圓。打中玩家扣血，打中教徒、教皇回 30 血。**站在兩圈之間的空隙就不會被打到**。蓄力時不能揮劍、不能用劍尖 |
| 這便是苦難 | 1 | 舉起右手，指尖以 0.4～0.7 秒的間隔放出兩道擴散圓環（半徑 290） |
| 受苦的詛咒 | 2 | 教徒或教皇倒下時**馬上**復活一隻；行動點不夠就扣自己 2% 生命 |

- 教徒倒下：偽神失去 3% 生命；教皇倒下：失去 10%
- **搶先出手**：保留 2 點行動點，玩家在自己的回合走進斬擊範圍時，有 35% 機率花雙倍（2 點）搶先揮劍（每個玩家回合最多一次）

**復甦的混亂教徒**（生命 130、行動點 2）：只會移動和揮砍十字架（前方扇形，有預告）。被教皇的圓環碰到會變強（每層 +30%，最多 3 層，頭上的黃色星星）。

**復甦的混亂教皇**（生命 220、行動點 3）：
- 擴散圓環（1 點）：以自己為中心，打到玩家扣血，碰到教徒讓教徒變強。敲鐘聲
- 聖牢籠（2 點）：在玩家位置框出一個方框（有預告），倒數結束時還在框裡就會被關住：出不了框，每個敵人回合開始都受傷。點框線攻擊牢籠（或用技能打到它）5 次就會破。場上同時只有一個

### 第二階段：褻瀆者的受難之日

生命剩 55%（扣掉 45%）時，偽神高舉反十字劍，所有教徒和教皇化作向上的光柱消失（放慢降調的雷射聲），被紅色光球包覆後變成有腳的樣子：

- 失去「受苦的詛咒」
- 立刻放大招 **神的狂怒**：畫面顯示「受難之日已然降臨」，全地圖依序降下 13 道有圓形預告的光柱（每 3 發有 1 發瞄準玩家）。之後每 5 回合一次
- 揮砍同時往兩個方向、制裁連射三發（每發都重新瞄準）、指尖圓環三道
- 會移動、會閃避（和殲滅矩陣一樣，閃避不一定成功）
- 變身演出中無敵，玩家暫時不能行動

## Boss：古代遺跡的殲滅矩陣

生命 200・攻擊 35・防禦 10・速度 10・行動點 13。

- **有智力、會移動**：核心、觸手、矩陣整體一起移動（每次 1 點，半徑 130），離玩家太遠會靠近。
- **保留行動點閃避**：每回合保留 4 點不用。在玩家回合被攻擊時（打核心但立場擋得住時除外）**有機率**花 2 點（雙倍）整體閃開，而且是在攻擊飛近時才移動：
  - 攻擊從越遠的地方來越容易閃：近身約 10%，距離 450 以上約 70%，中間線性變化
  - 每成功閃一次，下一次機率 ×0.6（到 Boss 自己的回合重置）
  - **閃避不是無敵**：閃避就是一次真正的移動（和玩家的應急移動一樣）。方向不一定判斷得對（攻擊從越遠來越容易選對：30%～80%），移動後還在攻擊範圍內就照樣受傷，畫面會顯示「閃避失敗」
  - 數值在 `config.js` 的 `dodge`，數值面板也能調

- **核心立場**：中間的能量核心一開始無敵。三個**能量矩陣**（各 85 生命，用觸手連在核心上）每破壞一個，核心受到的傷害依序變成 ×0.5 / ×1 / ×1.5。矩陣破壞後不會再生。核心裡的三顆紅點代表還活著的矩陣，立場泡泡也會越來越淡。
- **1 點**：揮動觸手（以觸手根部為圓心的扇形，有預告；觸手連同矩陣真的會掃過去）、矩陣周圍電流（離玩家最近的矩陣，圓形，有預告）、核心射擊（光彈 1-2-1-2，沒有預告）
- **2 點**：寬激光（有預告）、所有未破壞的矩陣同時射出環狀光彈（沒有預告）
- **大招**（3 點，第 3 回合起，之後每 3 回合一次）：矩陣環狀光彈 ＋ 核心朝三個方向（間隔 120°）各射 1-2-1-2
- 揮動觸手命中會把玩家**擊退** 90；電流命中會**扣 1 點行動點**（沒有行動點就不扣）
- 有預告的攻擊倒數 1 秒後判定；光彈會在場上飛，看到就移動躲開（敵人回合移動消耗 ×2）
- 攻擊傷害都是暫定，可以在「測試數值調整」裡拉

## 調數值

`battle.html` 最下方的「測試數值調整」可以即時改大部分數值，按「重新開始戰鬥」重來。重新整理會還原；要保存請改設定檔：

- `js/config.js`：共用規則、傷害公式、史萊姆、Boss、房間配置
- `js/characters/firsler.js`、`js/characters/ilshu.js`：角色的屬性、被動與技能（面板上的角色區塊由角色檔的 `tune` 決定）

## 角色成長

成長是局內系統：戰鬥頁上方的「角色成長」打開成長介面（教學房固定角色沒有），關閉介面後立刻套用到目前這場戰鬥（不重開）。等級可以直接拉（1–60），也可以加經驗；史萊姆房勝利 +150、Boss 房勝利 +800。測試期間成長暫存在瀏覽器的 localStorage；完整流程中每場遊戲會重新升級，之後再處理。

- 升級：每級依角色的 `growth` 增加生命、魔力、攻擊、防禦、速度（弗爾斯勒：3.5 / 2 / 0.9 / 0.3 / 0.1）
- 經驗：Lv N → N+1 需要 100 + 25 × (N−1)
- 每 5 等 1 個強化點：生命 +10、魔力 +10、攻擊 +2、防禦 +2、速度 +1
- 每 15 等行動點 +1（最多 +4）
- Lv 10 / 30 / 40 / 50 各強化一次 Q 或 E（每個技能兩次，先技能本身再附加效果），Lv 20 強化 W；每次二選一，再點一次可以取消
- 等級調低時，超出的強化點與強化會自動退回

規則在 `js/progression.js`，介面在 `js/build-panel.js`，各角色的強化選項寫在角色檔的 `upgrades`。

## 版面一致性

- 字型統一使用網路字型 Noto Sans TC（Google Fonts），畫布上的文字也是同一套；載入失敗才退回系統字型
- 介面不使用 emoji（各瀏覽器的 emoji 字型不同）
- 戰鬥頁以固定 1600px 寬設計，再依視窗大小整頁等比例縮放，所以不同瀏覽器、側邊欄、縮放比例下版面都一樣，只有大小不同

## 版本檢查

每個 js / css 檔都蓋有版本號（`python tools/stamp_version.py` 會一次全部更新）。網頁打開時會比對，只要有檔案不是同一版——上傳時漏掉、瀏覽器快取到舊檔、檔案不見——畫面最上方就會出現紅色提示，列出是哪幾個檔案。看到提示就重新上傳那些檔案，或按 Ctrl+F5。

## 放上 GitHub Pages

1. **`index.html` 要在 repo 的最外層**（打開 repo 首頁就要直接看到 `index.html`、`js/`、`css/`、`sounds/`）。
2. repo 的 **Settings → Pages → Build and deployment**：Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾 **/ (root)**，按 Save。
3. 等 1～2 分鐘，網址是 `https://你的帳號.github.io/repo名稱/`。之後每次推送都會自動更新。
4. **每次更新都要把壓縮檔裡的所有檔案一起上傳覆蓋**，只傳部分檔案很容易漏掉，版本檢查會跳出提示。

`.nojekyll` 這個空檔案是讓 GitHub 不要用 Jekyll 處理網站，保留就好。
